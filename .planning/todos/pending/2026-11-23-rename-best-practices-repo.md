After Phase 10.1 the best-practices repo holds agent-neutral masters and output for several agents, but the GitHub repo is still named `claude-best-practices`.

Pick an agent-neutral name and rename the repo. Then update every place that names it: the clone command (`sbx-bundle-clone`), any remote URLs in existing clones, docs and the rules that mention it.
