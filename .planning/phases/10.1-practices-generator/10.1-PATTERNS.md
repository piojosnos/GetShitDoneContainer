## Pattern Assignments

### Launchers / commands: `practices/generate.py`, `practices/check.py` (entry points)

**Analog:** `sbx/add.py` (tail), `sbx/cli.py`. Run as `uv run --locked python -m practices.generate` (RESEARCH), so no `bin/` launcher is needed in this repo.

**Module header + banners** (`sbx/registry.py` 1-8, same shape as `rules/python.md` "Module layout"):
```python
# ------------------------------------------------------------------------------
# The registry: one NAME.json file per sandbox under the sbx config directory
# ------------------------------------------------------------------------------
# An entry is data. ...
# ------------------------------------------------------------------------------

import json
from collections.abc import Mapping
from dataclasses import dataclass
from pathlib import Path
```
Order: stdlib, third party (`jinja2`, `yaml`), local. Constants section right after imports.

**main + Main / Entry Point** (`sbx/add.py`):
```python
def main(argument_list: list[str], environ: Mapping[str, str] = os.environ, repo_dir: Path = REPO_DIR) -> int:
    return run_command(COMMAND_NAME, partial(_add_sandbox, argument_list, environ, repo_dir))

# ------------------------------------------------------------------------------
# Main / Entry Point
# ------------------------------------------------------------------------------

if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```
Copy: `main` takes an injectable `repo_dir`, so tests call it against a `tmp_path` repo. Exit codes 0 clean, 1 drift or `PracticesError`, 2 usage.

**Error class and runner** (`sbx/cli.py` 20-70): copy `PracticesError(Exception)`, a `UsageError` with `args_text`, and `run_command(command_name, action) -> int` that prints `f"{command_name}: {text}"` to stderr and returns 1 or 2. Put the shared pieces in one module (e.g. `practices/cli.py`) since generate and check both need them (architecture rule: shared module at the second use). Keep `REPO_DIR = Path(__file__).resolve().parent.parent` (`sbx/cli.py` constants).

## Shared Patterns

### Fail closed with one error type
**Source:** `sbx/cli.py` `SbxError`, `run_command`. Apply to reader, render, output, check, generate. No bare `except:`; convert `OSError`, `UnicodeDecodeError`, `yaml.YAMLError` to `PracticesError` with the file name in the message.

### Banners, constants, naming
**Source:** `sbx/registry.py`, `rules/python.md` "Module layout". 82-column `# ---` rules, section titles, private helpers `_name`, constants UPPER_SNAKE after imports, type hints on public functions, no docstrings, blank lines around control flow, early return, `_list` / `_by_<x>_map` suffixes, ASCII-only comments, no planning IDs in code.

### Injectable roots for testability
**Source:** `sbx/add.py` `main(argument_list, environ, repo_dir)`, `sbx/registry.py` `config_dir(environ)`. Every generator function takes `repo_root: Path`; no module-level reading of the real repo except `REPO_DIR` default in `main`.
