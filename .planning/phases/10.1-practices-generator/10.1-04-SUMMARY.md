# Phase 10.1 Plan 04: Agent-neutral masters, the update skill and the real-repo output tests Summary

**Five masters reworded for any agent, `rules/best-practices.md` rewritten to send agents to the masters and the new `update-practice` skill, a README for the repo, and pytest checks on the real tree that the committed `generated/` is tracked, headed and equal to the masters; the generator also learned the optional `disable-model-invocation` skill key that `pre-pr-review` (merged into main meanwhile) needs.**

## Accomplishments

- The wording edits are in: `gsd-tools` runs from PATH, GSD steps are named as skills, `pr-reply` names the agent instructions file (`CLAUDE.md`, `AGENTS.md`), `communication` speaks of a multiple-choice picker if the agent has one.
- `rules/best-practices.md` finds the clone through `realpath` and `git rev-parse --show-toplevel`, names the masters and `generated/`, sends every change through `update-practice`, and names no host path or sandbox command. Its first line is still `# Where the practices live`, so it stays always loaded.

It repeats the push gate and the merge ban.
- `README.md` keeps the title, intro and License section and adds the layout schematic, the master format table and the three commands.
- 15 tests added in this plan: 8 for the new skill key (2 rejection rows and 2 read cases in `test_reader.py`, 4 output cases in `test_skill_output.py`), 3 in `test_masters_neutral.py`, 4 in `test_committed_output.py`. Suite: 88 passed (73 before).
