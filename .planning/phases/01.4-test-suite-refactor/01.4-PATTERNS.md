## Pattern Assignments

### Layout every new program follows (applies to every group file and runner)

**Analog:** `tests/host/h13-env-and-no-self-update.sh` (61 lines, the smallest complete check) and `best-practices/rules/shell.md` "Script layout" and "Libraries and programs" sections.

Header comment, `set -u`, source lib, banner per function, `Main / Entry Point` banner last (h13 lines 1-18, 51-61):

```bash
#!/usr/bin/env bash
# H-13: the environment is visible to docker exec, and Claude Code self-update is off.
# Depends on: nothing
set -u
. "$(dirname "$0")/lib.sh"
host_init

# --------------------------------------------------------------------------------
# Reads the container environment, the claude update reply and whether ~/.local/share/claude exists
# --------------------------------------------------------------------------------
read_environment() {
  ...
}

# --------------------------------------------------------------------------------
# Main / Entry Point
# --------------------------------------------------------------------------------
require_no_arguments "$@" || exit 2
```

Rules from `shell.md`: banner is `# ` plus exactly 80 dashes; every function has its own banner (libraries use `# name ARGS: what it does`); a library defines functions and variables only, runs nothing, sets no options; a helper goes in a library only when 2+ files use it; exit 0/1, usage error 2; programs read arguments first in Main. Libraries named `lib*.sh` are exempt from the `Main` banner in the lint.

Do not write `Phase N`, `D-NN`, `HT-0N`, `CONTEXT.md` or `.planning` in any file under `tests/` (guard rule 15 regex, `tests/guard.sh:24`). ASCII only. Braces always, blank line around control flow, full variable names, `xList` suffix for collections. Host-side code (`tests/guard/`, anything sourced from `tests/host/`) stays bash 3.2 (no `mapfile`, `declare -A`, `${x,,}`; empty array unbound under `set -u`).

```bash
# nowhere_matches REGEX FILE...: true if no line matches; prints the offending lines.
nowhere_matches() {
  local regex=$1; shift
```

### `tests/selftest/lib-expect.sh` (library)

Assertions (bundle-selftest.sh:40-60):

```bash
# expect NAME COMMAND...: PASS when the command succeeds.
expect() {
  local name=$1

  shift

  if "$@"; then
    echo "PASS: $name"
  else
    echo "FAIL: $name"
    FAILS=$((FAILS + 1))
  fi
}

# equals A B: true if the two strings are equal.
equals() { [ "$1" = "$2" ]; }

# has_text FILE TEXT: true if FILE contains TEXT.
has_text() { grep -Fq -- "$2" "$1"; }

# lacks_text FILE TEXT: true if FILE does not contain TEXT.
lacks_text() { ! grep -Fq -- "$2" "$1"; }
```

```bash
}

# cleanup_work: removes the work folder made above, and only that.

  case "$WORK" in

```

Make the case pattern use a stored prefix variable but keep the `case ... */sbx-<prefix>.*)` guard shape.
