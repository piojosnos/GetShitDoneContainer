## Phase Goal

ROADMAP.md Phase 2.2 goal (verbatim): "The best-practices bundle lives in its own GitHub repo. Every sandbox keeps its own clone in its sandbox folder, starts with the latest version, and can send improvements back as PRs. Updates survive restarts and rebuilds, and reach other sandboxes only after the user reviews and merges them."

Not in user-story form; quoted verbatim as in earlier phases.

This plan finishes the Mac side: H-27 drives the three wrappers and a push in a real container, H-16 proves the clone is live and survives a restart, H-09 adds the rebuild, H-18 proves the managed settings in the real image, and the H-19 helper walks the real flow with the real private repo.

Planning notes:
- H-27 runs in the no-sandbox stage, like H-17: one `docker run --rm --network none` with the compose restrictions on a fresh folder `RUN/h27-PID-TIME`, so it never touches the running test sandbox and can run twice on one run folder. Its in-container script prints `STEP NAME STATUS` lines and writes outputs into that folder; the Mac side reads them. The offline flag also proves the local clone and push need no network.
- Order in run-all.sh: H-27 runs before the sandbox stage, so H-16's push to `RUN/bundle-origin.git` cannot change what H-27 clones (H-27 clones a bare copy anyway).
- H-16 never deletes: it moves the rules link and one fixture skill aside with `mv`, so the printed cleanup removes them with the run folder. A pull with an uncommitted edit works because the pulled commit adds a new file only.
- H-18's deny scenario needs a Read before each Edit (Claude's Edit tool refuses an unread file). The link-path edit and the real-path edit of the same skill use different new texts, so the result shows which one went through.
- Research assumptions this plan's checks settle on the Mac: A1 (an interactive session loads the linked rules with no approval dialog: H-19 step), A2 (managed settings behave as the --settings file: H-18), A3 (auto mode treats the clone like the working folder: H-19 observation), A4 (the relative links resolve on the Mac: H-15 and H-16), A7 (gh login from a container shell with no browser: H-19 step).
- Reversibility: test code only; reversible.
