## Decisions Made

- The H-27 in-container script is held with `IFS= read -r -d ''` from a quoted heredoc (read returns 1 at end of input, hence `|| true`), avoiding bash 3.2 command substitution parsing of heredoc text.
- H-18 builds its three tool scripts from `read_call`, `edit_call` and `write_call` helpers rather than one long `printf` line.
- H-18 reports separately whether the bypassPermissions or the acceptEdits real-path edit failed, using the intermediate text `h18 bypass edit`.
