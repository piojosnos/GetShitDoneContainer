# Phase 02.2: Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| sandbox folder to the start hook | the clone is user- and agent-writable content the hook links into Claude's config | rules and skills text Claude loads every session |
| versions.env to the image | the URL line becomes image ENV every shell trusts | the bundle repo URL |
| container env to the hook | `SBX_BUNDLE_DIR` and `CLAUDE_CONFIG_DIR` decide what the hook touches | paths |
| Claude to the sandbox folder | managed settings decide which paths Claude's tools may write | file edits |
| sandbox shell to GitHub | gh's token and git's helper allow clone, push and PR | gh token (secret), rule changes |
| dev sandbox to GitHub | repo creation, branch push and PR under the user's account | repo content |
| host checks to the Mac and GitHub | checks write only under their run folder; automated checks use local bare origins | test logins (secret) in the run folder |
| docs to the user | SANDBOX.md tells the user what Claude may change | none |
