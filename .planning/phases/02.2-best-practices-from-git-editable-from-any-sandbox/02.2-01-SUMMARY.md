- Tracer proven end to end without Docker: the real hook linked a clone of a local bare repo, and Claude 2.1.285 listed the rule by its clone path and the skill as User.
- The hook is a link maker: `rules` is a link `../../best-practices/rules`, each skill a link `../../../best-practices/skills/NAME`, the names listed one per line in `.best-practices-skills`.
