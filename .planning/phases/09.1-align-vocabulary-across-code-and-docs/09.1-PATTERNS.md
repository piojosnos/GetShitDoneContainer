```markdown
| Where | What |
|---|---|
| `piojosnos/claude-best-practices` (private GitHub repo) | The source: ... Named by `BUNDLE_REPO_URL`. |
```

### Check and step files (CHECK_LIST naming)

**Analog:** `base/selfcheck/checks/120_env_bundle.py` (whole file). The pins in one check:

```python
from paths import BUNDLE_DIR, VERSIONS_FILE
def bundle_env_result(versions_file: Path = VERSIONS_FILE, environment_map=os.environ) -> CheckResult:
    pin_map, missing_result = pin_map_or_missing(["BUNDLE_REPO_URL"], versions_file)
    ...
    {"BUNDLE_REPO_URL": pin_map["BUNDLE_REPO_URL"], "SBX_BUNDLE_DIR": str(BUNDLE_DIR)},
def _check_env_bundle() -> CheckResult: ...
CHECK_LIST = [Check("env-bundle", _check_env_bundle)]
```

Rename together: file name (`NNN_snake.py`, pattern `^[0-9]{3}_[a-z0-9_]+\.py$`), banner header, public result function, private `_check_*`, the `Check("kebab-name", ...)` (pattern `^[a-z0-9]+(-[a-z0-9]+)*$`), imports from `paths.py`, and the header text.

**Step and check twin** (names intentionally equal; keep that symmetry):

`base/selfcheck/checks/030_state_folders.py:73`: `Check("state-folders", _check_state_folders),`

## Shared Patterns

### Rename order for every family
**Source:** RESEARCH "Dependency order of a rename family".
```
git mv files -> imports and loaders -> names (CHECK_LIST, STEP_LIST, env, pins, ARG/ENV)
 -> messages -> their test pins -> inventory lists
 -> uv run pytest -q ; bash tests/guard/run-all.sh ; bash tests/selftest/sbx/run-all.sh
 -> read each hit in context; grep only as the final sweep
```
Baseline: 463 pytest pass, guard "All rules hold.", selftest/sbx "All cases pass."

### Keep the exec bit and history
Use `git mv`, then `git diff --summary` and check for `rename ...` and no `mode change 100755 => 100644` (sandbox edits drop the exec bit).

### Guard word ban in `bin/`
`tests/guard/isolation.sh:47`: `nowhere_matches '\b(rm|rmdir|prune|kill|down)\b|--volumes' $otherFileList` over every `bin/` file except `sbx-rm`. New wording in `bin/` must avoid those words. Do not reflow the `--volumes-from ${namePrefix}{sandbox_name(` line in `base/selfcheck/root_owned_scan.py` (`isolation.sh:84-99`).

### Names that stay
CA bundle (`280_extra_ca.py`, `test_extra_ca.py`, check `extra-ca-system-bundle`), third-party names (`CLAUDE_CONFIG_DIR`, `CURSOR_CONFIG_DIR`, `GH_CONFIG_DIR`, `safe.directory`, `additionalDirectories`, `user.containers.override_stat`), GitHub repo `piojosnos/claude-best-practices`, directory name `best-practices`, macOS-specific facts (BSD tools, Docker Desktop, Keychain), `EntryHook` in `tree_walk.py`, and the tests that assert `start.d` is gone (`test_init_inventory.py:141-145`, `test_image_roots.py:51-52`; only their "folder" wording changes).

### Prose and source rules
No em dash, en dash, `--` or spaced hyphen as punctuation; punctuation outside closing quotes; ASCII only in source; no D-NN or phase IDs in committed files; stage explicit paths (never `git add -A`; `.DS_Store`, `.gsd/`, `pending-practices.md` and an export tarball are untracked). Code, `.planning/`, `.claude/CLAUDE.md` and the best-practices repo each ship in their own PR.
