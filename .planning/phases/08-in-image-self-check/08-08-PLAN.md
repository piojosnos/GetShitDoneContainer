## Design of the owner fix (Claude's discretion under D-04)

- `--volumes-from sbx-NAME` gives the throwaway container the sandbox's own mount at the same path, so the hint needs no Mac folder path (the sandbox cannot know `SBX_DIR`).
- `sbx-base:local` is built by every `./build.sh` run, holds `chown`, and `--entrypoint chown` skips the start check, as MIGRATION.md step 6 does with the Claude image.
- `--network none` and `--rm`: nothing reaches the network and nothing is left behind.
- The command chowns the whole state folder with `-R`, like the migration recipe; chown carries on past a file it cannot change, and the cache folders the walk skips do not affect the check.
- Docker Desktop's file sharing may accept an owner change from the sandbox user (the GSD sync todo of 2026-11-08 saw that), but the hint must work on every engine the self-check runs on, including a native Linux bind mount; the throwaway root container does.
- Plan 08-09 proves the command on real Docker inside H-34, and 08-11 runs it on the Mac.

Project rules for every file this plan touches: imperative loops (no comprehensions or generator expressions in new code), a blank line before and after each control-flow block, full names, collection suffixes (`_list`, `_set`, `_by_x_map`), no doc-comments, ASCII only, no phase, decision or review IDs in source, tests or READMEs, and no dash used as punctuation in Markdown.
