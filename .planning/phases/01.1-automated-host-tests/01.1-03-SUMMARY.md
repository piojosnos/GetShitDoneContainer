## Decisions Made

- **Guard before lib.sh.** `host_init` calls `docker container inspect` to find the run folder, so the terminal guard must come before sourcing and initialising. The plan's verify (stdin from `/dev/null`, no "not found" from a missing docker) passes because of this ordering.
- **Guard text duplicated three times.** Four lines each; `lib.sh` is off limits for this plan and a new shared file is not in the plan's file list. Consolidation is possible later if a fourth helper appears.
- **Second sandbox assertion in H-09.** After `compose_up` the helper calls `require_test_sandbox` again before opening Claude, so the interactive step never runs against a container that is not the test sandbox.
- **Record table removed.** The old fill-in table duplicated the run-all summary; the checklist now asks for the pasted summary and helper lines.
