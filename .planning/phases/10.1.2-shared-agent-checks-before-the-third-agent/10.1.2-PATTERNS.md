## Pattern Assignments

### `base/selfcheck/agent_description.py` (model, transform)

**Analog:** `base/selfcheck/step_files.py` lines 8-35 and `check_result.py` lines 8-35.

Header banner (80-dash rules, title, 2-line why: "The image puts this file in /usr/local/lib/sbx-selfcheck/"), then:
```python
from dataclasses import dataclass
from pathlib import Path

@dataclass(frozen=True)
class StepFileKind:
    list_name: str
    ...
```
Stdlib only (no import of `check_result`), so no import cycle and both launchers can import it. Fields (names are discretion; collection suffix rule applies): `name`, `config_dir`, `home_link_list`, `login_file`, `login_hint`, `environment_value_by_name_map`, `image_root_list`, `versions_field_list` (label, pin name), `gsd_option`. Section banner `# --- ... ---` style as in `step_files.py` ("What differs between the runners").

### `base/selfcheck/agent_checks.py` (service, transform)

**Analog:** the 8 twins; nested-def-returning-`Check` precedent is `step_files.py` `load_failure_check`:
```python
def load_failure_check(name: str, detail: str) -> Check:
    def report_load_failure() -> CheckResult:
        return failed(detail, rebuild_hint())

    return Check(name, report_load_failure)
```
Must live in `base/selfcheck/` (both `sbx-selfcheck` and `sbx-init` can import it; `sbx-selfcheck` cannot import `base/init`). Imports it needs (names verbatim from twins):
```python
from agent_config import gsd_synced_result, login_file_result
from best_practices_links import best_practices_links_result
from check_result import Check, CheckResult
from environment_values import environment_values_result
from home_links import home_links_result
from image_ownership import image_ownership_result
from paths import BEST_PRACTICES_DIR
from pins import pin_map_or_missing
from protected_paths import protected_paths_result
from versions_text import versions_line_result
```
**Core pattern**, one private `_x_check(agent) -> Check` per concern, nested def, f-string name `f"{agent.name}-<suffix>"`. Suffixes: `env`, `home-links`, `credentials`, `gsd-synced`, `best-practices-links`, `image-root-owned`, `image-paths-protected`, `versions-line`.

Per-call lines to wire (from the twins):
- env: `environment_values_result(agent.environment_value_by_name_map)`
- home links (`cursor/selfcheck/040_home_links.py` loop form, the better one):
```python
link_target_list = []

for home_link in _HOME_LINK_LIST:
    link_target_list.append((home_link, AGENT_CONFIG_DIR))

return home_links_result(link_target_list)
```
- credentials: `login_file_result(agent.login_file, agent.login_hint)`
- `gsd_synced_result(agent.config_dir)`
- `best_practices_links_result(agent.config_dir, BEST_PRACTICES_DIR, agent.name)`
- `image_ownership_result(agent.image_root_list)`, `protected_paths_result(agent.image_root_list)`
- versions line (`claude/selfcheck/120_versions_line.py` lines 17-25):
```python
pin_map, missing_result = pin_map_or_missing(["CLAUDE_CODE_VERSION", "CCUSAGE_VERSION"])

if missing_result:
    return missing_result

return versions_line_result(f"claude {pin_map['CLAUDE_CODE_VERSION']} | ccusage {pin_map['CCUSAGE_VERSION']} | ")
```
Build prefix with a `for label, pin_name in agent.versions_field_list` loop (`f"{label} {pin_map[pin_name]} | "`). No lambdas, no comprehensions. Public function first (`agent_check_list`), private builders below in call order, one comment rule between members.

### `base/init/agent_steps.py` (service, transform)

**Analog:** `claude/init/050_gsd_sync.py` lines 8-26 and `claude/init/900_best_practices_links.py` lines 8-22.

Imports from current files:
```python
from pathlib import Path
from typing import Callable

from best_practices_linker import link_best_practices
from check_result import Check, CheckResult
from gsd_sync import gsd_sync_result
from paths import BEST_PRACTICES_DIR
```
plus `from agent_description import AgentDescription` (base/selfcheck is on `sbx-init`'s path).

Core (current gsd step, to become the builder; `sync_function` injection moves from the step function to the builder):
```python
def _step_claude_gsd_sync(
    sync_function: Callable[[Path, str], CheckResult] = gsd_sync_result,
) -> CheckResult:
    return sync_function(AGENT_CONFIG_DIR, "--claude")

STEP_LIST = [Check("claude-gsd-sync", _step_claude_gsd_sync)]
```
becomes `gsd_sync_step_list(agent, sync_function=gsd_sync_result) -> list[Check]` with nested zero-arg `step_gsd_sync`, name `f"{agent.name}-gsd-sync"`. Second builder `best_practices_links_step_list(agent)` calls `link_best_practices(agent.config_dir, BEST_PRACTICES_DIR, agent.name)`, name `f"{agent.name}-best-practices-links"`.

## Shared Patterns

### File header and member separators
**Source:** every file read (e.g. `base/selfcheck/step_files.py` l.1-7; `claude/selfcheck/030_env.py` l.1-6, 13-15)
80-dash rule lines, title, 2-line why naming the image destination directory; `# --- TEXT ---`-style section banner (e.g. `# Check entries`) before each group; one full-width rule line between members.

### Naming and style
**Source:** `.claude/CLAUDE.md`
Collection suffixes (`home_link_list`, `environment_value_by_name_map`); full names; nested `def` over lambdas; braces/blank lines around `for` and `if`; ASCII only; no planning IDs in code; type hints on public functions.

### Import path
**Source:** `base/selfcheck/sbx-selfcheck` l.21-22, `base/init/sbx-init` l.23-25
`sbx-selfcheck` sees base/selfcheck + agents; `sbx-init` also sees base/init. Anything the check builder imports must be in base/selfcheck. pytest `pythonpath` (pyproject.toml l.16) is a superset, so unit tests alone will not catch a wrong location; use the `-I` subprocess test.

### Dockerfiles
No change: `COPY` globs already cover `base/selfcheck/*.py`, `base/init/*.py`, `<agent>/selfcheck/*.py`, `<agent>/selfcheck/lib/*.py`, `<agent>/init/*.py`.
