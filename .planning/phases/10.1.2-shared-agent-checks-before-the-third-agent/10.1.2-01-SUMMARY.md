# Phase 10.1.2 Plan 01: Shared agent checks from one description Summary

**The eight twin selfcheck files of each agent became one frozen `AgentDescription` per agent and one `agent_check_list` builder in `base/selfcheck/`, loaded through a thin `030_agent_checks.py`; all 24 agent check results are byte-identical to the fork point.**

## Performance

- **Duration:** about 25 min
- **Tasks:** 2 of 2 (Task 1 tracer: Claude; Task 2: Cursor)
- **Files:** 39 changed in code, plus the planning snapshot tool

## Accomplishments

- `AgentDescription` (name, config dir, home links, login file and hint, environment values, image roots, versions fields, GSD option) lives in `base/selfcheck/agent_description.py`, standard library only.
- `agent_check_list(agent)` builds `<agent>-env`, `-home-links`, `-credentials`, `-gsd-synced`, `-best-practices-links`, `-image-root-owned`, `-image-paths-protected`, `-versions-line`, one nested-closure builder per check.
- `claude_shared.AGENT` and `cursor_shared.AGENT` hold each agent's values next to the kept `AGENT_NAME`, `AGENT_CONFIG_DIR` and Cursor's `CLI_CONFIG_FILE`; the separate `IMAGE_ROOT_LIST` constants are gone.
- 16 twin check files and 16 twin test files removed; the agent-specific checks (`010_tool_*`, `020_tool_ccusage`, `050_no_home_copy`, `050_self_update_off`, `090_managed_settings`) and `runner.py`, `step_files.py`, `sbx-selfcheck` are untouched.
- Check counts stay at 13 (Claude) and 11 (Cursor); only the order moved: tool checks, the eight built checks, then the agent's own checks (`test_inventory.py` lists updated).
