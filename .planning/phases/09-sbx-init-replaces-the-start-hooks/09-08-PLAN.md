<objective>
Make the host side independent of the image's start code: move the sandbox name rule from `base/sbx-start-lib.sh` into `bin/sbx-lib.sh`, and remove the readiness poll that waited for start hooks. Covers the host half of INIT-03, per D-01 and D-04. Runs in wave 1 because it touches no init file; plan 09-09 can only delete the start library after this plan (RESEARCH Pitfall 1).

Purpose: every `sbx-*` host script sources the start library through `load_name_rule` today; deleting the library first would break them all.
Output: the edited host lib and scripts, and the sbx self-test no longer copying the start library.
</objective>
