<objective>
Move the host test chain onto the new start: the test sandbox's `compose_up` runs `sbx-init` where it used to wait for start hooks, H-34 runs `sbx-init` before each self-check, and the checks that tested the entrypoint or its hooks go. Covers the host side of INIT-03 and a real-image rerun of INIT-02, per D-03 and D-04 (Claude's discretion on which host checks change or go, as RESEARCH "Host check fates" proposes).

Purpose: the chain checks lean on the entrypoint's side effects (state folders, GSD synced, links); running sbx-init in `compose_up` keeps them working without an `sbx-init` call in every check (RESEARCH Pitfall 7).
Output: edited host test library and checks, three deleted checks.

These files run on the Mac: stock bash 3.2 and BSD tools. Docker is not in the dev sandbox, so `bash -n`, the guard's shellcheck rule and greps are the checks here; plan 09-13 runs them on the Mac. The new behaviour checks (H-16, H-27, H-35) are plan 09-11.
</objective>
