<objective>
Port the two jobs the start hooks did before any shell could start an agent: the GSD sync into the agent's config folder (both agents) and the static update channel (Cursor only), as init step files on the runner of plan 09-01. The self-check twins keep the verification (D-12) and their fix lines now name sbx-init. Covers INIT-01, per D-06, D-12, D-13 and D-25.

Purpose: the GSD sync is what makes the image's GSD win; without it in sbx-init a fresh sandbox has no GSD. The Cursor channel keeps the CLI from updating itself.
Output: `base/init/gsd_sync.py`, three agent step files, one shared Cursor constant, hint updates in two checks, and their tests.

Discretion choices recorded here: the installer output stays in a temp file whose path the FAIL line names (one line per step, the full output one `cat` away), and the time limit stays 300 s as in the hook.
</objective>

base/init/gsd_sync.py (banner "The GSD sync into an agent's config folder", "The image puts this file in /usr/local/lib/sbx-init/."): constants `GSD_INSTALLER_COMMAND = "gsd-core"`, `GSD_TIME_LIMIT_SECONDS = 300`, `_LOG_PREFIX = "sbx-init-gsd-"`. Public `gsd_sync_result(config_dir: Path, agent_option: str, installer_command: str = GSD_INSTALLER_COMMAND, time_limit_seconds: int = GSD_TIME_LIMIT_SECONDS, environment_map: Mapping[str, str] = os.environ, log_dir: Path | None = None) -> CheckResult` (`log_dir` None means the system temp folder; tests pass a folder of their own), split into small private helpers:
- make the folder: `config_dir.mkdir(parents=True, exist_ok=True)`; an OSError FAILs with `cannot make {config_dir}: {e.strerror}` and `make the state folder of the sandbox writable by your Mac user, then run sbx-init again`, and the installer is not started.
- run: a `tempfile.NamedTemporaryFile(prefix=_LOG_PREFIX, suffix=".log", dir=log_dir, delete=False)` as stdout, stderr merged into it, stdin `subprocess.DEVNULL`, `start_new_session=True`, `env=dict(environment_map)`, argument list `[installer_command, agent_option, "--global", "--config-dir", str(config_dir)]` (a list, never a shell string). Use `subprocess.Popen` then `wait(timeout=time_limit_seconds)`; on `TimeoutExpired` call `os.killpg(process.pid, signal.SIGKILL)` and wait again. A `FileNotFoundError` from Popen FAILs with `{installer_command} is not on PATH` and the rebuild hint.
- outcomes: exit 0 removes the log and passes `the GSD installer finished into {config_dir}`; a non-zero exit FAILs with `the GSD installer exited {code} (last line: '{last non-empty line}'); its output is in {log}`; the time limit FAILs with `the GSD installer did not finish within {time_limit_seconds} s and was stopped; its output is in {log}`. Both failure hints: `read {log}, fix what it names, then run sbx-init again`. The log is kept on failure.
Do not read the synced version file or compare versions here (D-12).
