<objective>
Make the in-image commands match the new start: the agent wrappers refuse until `sbx-init` has passed in this container and then start the agent from the off-PATH agents folder; `sbx-bundle-clone` relinks by running `sbx-init`; `sbx-gh-login` points at `sbx-init` when the state folders are missing. Covers INIT-04 (wrapper half), per D-11, D-19 to D-21, D-27 and D-29. Folds the todo "sbx-claude waits 5 seconds when nothing is linked".

Purpose: the wrapper refusal is what keeps a user from running an agent in a sandbox whose GSD and links were never set up.
Output: two rewritten wrappers, two edited helpers, and pytest tests that run the real shell scripts.

The wrappers stay thin shell (the project rule: logic in Python, shell for thin exec wrappers). The two override variables exist so the tests can run the real scripts without touching /home/sandbox or /opt; they are documented in the wrapper header.
</objective>
