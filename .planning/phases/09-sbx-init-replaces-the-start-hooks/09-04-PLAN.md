<objective>
Link the best-practices clone into the agent's config folder as the last init step, without ever touching a user's own skill: replace the bash linker's remove-then-link with a three-way rule that recognises init's own links by where they point. Make the self-check verify what the old list file stood for. Covers INIT-05, per D-07, D-12 to D-17, D-23, D-24, D-28 and D-29. Folds the todos "Bundle hook deletes a user skill with a bundle skill's name" and "Bundle hook is not atomic and verifies only the rules link".

Purpose: the old hook ran a recursive delete on `skills/NAME` and on `rules`, so a user skill with a bundle skill's name was lost at every start.
Output: `base/init/best_practices_link.py`, one step file per agent, the shared link helpers in `bundle_links.py`, the updated check, and tests.
</objective>
