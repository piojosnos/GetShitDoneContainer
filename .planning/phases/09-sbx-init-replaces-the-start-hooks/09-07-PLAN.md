<objective>
Switch the images to the new start: remove the entrypoint and the start hook folder, install `sbx-init` with the shared steps and each agent's step files, and move `claude` and `cursor-agent` off the PATH into a root-owned agents folder. Align the self-check's image roots with the new layout in the same plan, so no root goes missing (RESEARCH Pitfall 2). Covers INIT-03 (image side), INIT-04 (agents off the PATH) and the image half of INIT-01, per D-02, D-05, D-19 and D-25.

Purpose: until this plan the images still run the old entrypoint; after it, a container start only sleeps and `sbx-init` is the one way to set a sandbox up.
Output: three Dockerfiles, compose comments, image roots and ownership rules, and the step inventory test.

Discretion choice recorded here: the agents folder `/opt/sbx/agents/bin` is made by the base image and listed in the base roots (it names no agent), and each agent image only adds its link, the same way agent images add files to `/etc/sbx/selfcheck.d`.
</objective>
