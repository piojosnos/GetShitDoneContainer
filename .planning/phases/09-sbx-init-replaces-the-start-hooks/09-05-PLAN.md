<objective>
Teach the self-check the two facts this phase adds: whether `sbx-init` passed in this container (the marker) and whether the agents stay off a plain PATH, and make the agent tool checks find the agents where the wrappers do. Covers the self-check side of INIT-04 and D-13, per D-12, D-13, D-18, D-19 and D-20.

Purpose: `sbx-selfcheck` is the one place that verifies (D-12); without these checks nothing would notice a missing init or an agent linked back onto the PATH.
Output: one shared check, two agent checks, two helpers in `tools.py`, counts in the inventory test and H-34.

Honest asymmetry, flagged: the off-path check takes the agents folder out of PATH before it searches, instead of reading a fixed "plain" PATH, because `sbx-selfcheck` may be run from inside an agent session whose PATH the wrapper extended (for example Claude running it through its shell tool).
</objective>
