## Pattern Assignments

### `cursor/Dockerfile` (config, batch)

**Analog:** `claude/Dockerfile` (whole-file shape), Node RUN in `base/Dockerfile` (download + checksum + arch map).

**Header, ARG default, single FROM** (`claude/Dockerfile:1-9`; the guard allows exactly `ARG BASE_IMAGE=sbx-base:local` and `FROM ${BASE_IMAGE}`):
```dockerfile
# ------------------------------------------------------------------------------
# The Claude image: ...
# ------------------------------------------------------------------------------
# BASE_IMAGE keeps a default because it names the local base tag, not a version.
# Pins come from versions.env through build.sh; no other ARG has a default.
# ------------------------------------------------------------------------------
ARG BASE_IMAGE=sbx-base:local
FROM ${BASE_IMAGE}
```

**Required pin pattern, root install, state link** (`claude/Dockerfile:17-26`):
```dockerfile
USER root
ARG CLAUDE_CODE_VERSION
RUN : "${CLAUDE_CODE_VERSION:?CLAUDE_CODE_VERSION is not set; build with ./build.sh}" \
    && ... \
    && ln -s /home/sandbox/workspace/state/claude /home/sandbox/.claude \
    && chown -h sandbox:sandbox /home/sandbox/.claude
```
For Cursor: two links (`~/.cursor` and `~/.config/cursor`, with `mkdir -p /home/sandbox/.config` first, both into `state/cursor`, both `chown -h sandbox:sandbox`).

**Arch map and checksum** (`base/Dockerfile:55-68`, read lines 56-61 when writing: `dpkg --print-architecture` mapped to the vendor's arch name, `curl -fsSLO`, `sha256sum -c`). Base's Node RUN pipes `curl | grep | sha256sum -c -`; the base Dockerfile sets `SHELL ["/bin/bash","-o","pipefail","-c"]` at line 20. `cursor/Dockerfile` has no SHELL line, so write the RUN without a pipe (download both files, `sha256sum -c file.sha256`, then `tar`), as in RESEARCH.md "cursor/Dockerfile skeleton", or hadolint DL4006 fires. Set `WORKDIR /tmp` for the download and restore `WORKDIR /home/sandbox/workspace` after (base ends at `base/Dockerfile:227` with that WORKDIR, so a bare `curl -O` would land on the mount point).

**ENV block** (`claude/Dockerfile:50-56`):
```dockerfile
ENV CLAUDE_CONFIG_DIR=/home/sandbox/workspace/state/claude \
    SBX_STATE_DIRS="${SBX_STATE_DIRS} claude" \
    ...
```
Cursor: `CURSOR_CONFIG_DIR=/home/sandbox/workspace/state/cursor` and `SBX_STATE_DIRS="${SBX_STATE_DIRS} cursor"`. `BUNDLE_REPO_URL` and `SBX_BUNDLE_DIR` ENV and the `ARG BUNDLE_REPO_URL` check move to `base/Dockerfile` (D-02), so they are not repeated here. Do not set `DISABLE_UPDATES`; self-update is stopped by the `02-no-self-update` hook (`"channel": "static"`).

**Hooks copy** (`claude/Dockerfile:67-72`):
```dockerfile
COPY claude/start.d/ /etc/sbx/start.d/
COPY --chmod=755 claude/bin/ /usr/local/bin/
RUN chmod 755 /etc/sbx/start.d/* ...
```
Cursor copies only `cursor/start.d/` (no `bin/`; D-14 has no launcher). Requires `!cursor` in `.dockerignore`.

**Tool versions line** (`claude/Dockerfile:82-85`):
```dockerfile
RUN { printf 'claude %s | gsd %s | ccusage %s | ' ...; cat /etc/sbx/tool-versions; } > /tmp/tool-versions \
    && mv /tmp/tool-versions /etc/sbx/tool-versions \
    && chmod 644 /etc/sbx/tool-versions \
    && grep -Eq '^claude [0-9.]+ \| gsd ... $' /etc/sbx/tool-versions
```
Cursor: prefix `cursor-agent %s | ` and loosen the grep to the `YYYY.MM.DD-hex` form. GSD moves to base, so base's own line gets `gsd G | node ...` (`base/Dockerfile:192-200`, grep at 199) and the Claude prefix becomes `claude C | ccusage U | ` (Claude line order changes: `ccusage` before `gsd`; edit `tests/host/h30-version-line.sh:26` `expectedLine` to match).

**Smoke test, last RUN** (`claude/Dockerfile:93-100`):
```dockerfile
USER sandbox
RUN test "$(claude --version)" = "${CLAUDE_CODE_VERSION} (Claude Code)" \
    && ... \
    && { test -z "$(ls -A /home/sandbox/workspace)" || { echo "Files under the mount point:"; find /home/sandbox/workspace; exit 1; }; }
```
Cursor: `smokeHome="$(mktemp -d)" && test "$(env -u CURSOR_CONFIG_DIR HOME="$smokeHome" cursor-agent --version)" = "${CURSOR_AGENT_VERSION}"` before the same empty-mount check (`cursor-agent --version` writes `cli-config.json` through the dangling link otherwise). The GSD identity check (`gsd-tools runtime-identity --raw`) moves to base's smoke test (`base/Dockerfile:217-225`).

**Pin record, last layer** (`claude/Dockerfile:107`): `COPY --chmod=644 versions.env /etc/sbx/versions.env`.
