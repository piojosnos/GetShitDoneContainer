## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug in the plan text] Changing the agent needs `--unregister`**
- **Found during:** Task 2
- **Issue:** the plan says "remove the sandbox with `sbx-rm NAME` and add it again". `sbx-rm NAME` alone keeps the registry entry, and `sbx-add` refuses a name that is still registered.
- **Fix:** the README says `sbx-rm NAME --unregister`, then `sbx-add NAME HOST_PATH [claude|cursor]` with the same folder. It also says that editing `SBX_AGENT=` then `sbx-start NAME` recreates the sandbox on the other image (`runs_older_image` and Compose do this).
- **Files modified:** `README.md`
