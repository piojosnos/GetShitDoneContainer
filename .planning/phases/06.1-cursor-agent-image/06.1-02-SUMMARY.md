## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug in a verify command] BRE pattern fails under this sandbox's grep**
- **Found during:** Task 1, third verify command
- **Issue:** `grep -c 'npm install -g "@opengsd/gsd-core@${GSD_CORE_VERSION}"'` (no `-F`) returns 0 here because the sandbox `grep` is ugrep, which reads `${` as regex syntax. The Dockerfile line was correct; the same count with `-F` is 1, and the guard rule uses `-F`.
- **Fix:** reran that command with `-F`; the awk order check and both `main` diffs then passed. No file changed for this. The plan's own command should work under GNU grep on the Mac.
- **Commit:** none

**2. [Rule 2 - user rule] Linker functions return instead of exit**
- **Found during:** Task 3
- **Issue:** the plan sketches `exit` inside `check_arguments`, `check_inputs` and `check_links_reach_clone`; the user's shell rules want a function to return non-zero and the caller to decide.
- **Fix:** the functions `return 1`; Main runs `check_arguments "$@" || exit 2`, `check_inputs || exit 1` and `check_links_reach_clone || exit 1`. Exit codes and messages are exactly the planned ones; the self-test proves it.
- **Files modified:** `base/bin/sbx-link-bundle`
- **Commit:** `3f9b1c2`

**3. [Process] Task 3 split into RED and GREEN commits**
- The TDD flow wants the failing test committed first. Content is as planned.
