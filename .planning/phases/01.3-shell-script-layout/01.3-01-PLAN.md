<interfaces>
Reporting API in tests/host/lib-report.sh (output format is fixed by D-06):
- pass ID TEXT: prints "PASS: ID TEXT" (moved verbatim).
- fail ID TEXT [DETAIL...]: prints "FAIL: ID TEXT", then each DETAIL on its own line indented by 6 spaces (moved verbatim).
- info TEXT: prints "INFO: TEXT" (moved verbatim).
- problemList=() and add_problem MESSAGE: appends MESSAGE (moved verbatim with their comments).
- report_result ID FAIL_SUMMARY PASS_TEXT (new): when problemList is not empty, calls fail ID FAIL_SUMMARY with every problem as a detail, empties problemList, returns 1; otherwise calls pass ID PASS_TEXT and returns 0. Tests the count first (the existing comment: bash 3.2 with set -u treats an empty array as unbound).
- report_check ID FAIL_SUMMARY PASS_TEXT (signature unchanged): report_result with the same three arguments, then exit 0 when it returned 0, exit 1 otherwise.
- stop_check ID SUMMARY [DETAIL...] (new): fail with all its arguments, then exit 1.
- pass_check ID TEXT (new): pass ID TEXT, then exit 0.
- first_lines TEXT [COUNT] (moved verbatim): first COUNT lines (default 3), each followed by a space.
- join_lines TEXT [SEPARATOR] (new): the body is printf '%s\n' of TEXT piped into tr turning each newline into SEPARATOR (default one space, via the expansion of 2 with a default of a space). Byte-equal to the inline printf and tr sites it replaces, trailing separator included.

Frozen callers that must keep working unchanged (do not edit these files):
- tests/host-selftest.sh line 545: lib_eval runs ( . tests/host/lib.sh; host_init; eval SNIPPET ) and calls make_run_dir, claude_pin and expected_arch.
- tests/host-selftest.sh line 1048: copies only tests/host/*.sh into a scratch repo, then runs coexistence.sh there. Libraries must be flat files next to lib.sh, never a subfolder.
- tests/guard.sh scans tests/host/*.sh and tests/host/manual/*.sh, comments included, for: planning IDs (D-NN, "Phase N", .planning, CONTEXT.md), any sbx- name other than sbx-hosttest, sbx-base, sbx-claude, and cc_ outside coexistence.sh and the snapshot grep line. Code lines (not comments) must not contain rm, rmdir, unlink, prune, a read command, a tty flag, stat -c outside a line with in_container or docker exec, a bare word timeout, declare -A, mapfile, sed -i, echo -e, jq or python.

Bash pitfalls that change output if ignored (RESEARCH "Common Pitfalls"):
- Declare local on one line and assign on the next; a status read with $? must come right after the assignment.
- Never call add_problem, report_check or stop_check inside a command substitution or a pipeline stage: it runs in a subshell and the problem or the exit is lost.
- Arguments of report_check expand before the call; every variable in the PASS text must already be set under set -u.
Conventions for every file this plan touches (.claude/CLAUDE.md, ~/.claude/code-conventions.md): braces always; a blank line before and after every if, for, while and case block (else chains stay attached); full variable names (only i, j, k and e are short); ASCII only; no dash used as punctuation in comments (no em or en dash, no spaced double hyphen); no planning or review IDs in source (no D-NN, WR-NN, AR-NN, T-NN, phase numbers, .planning paths); no comment about what the code used to do; host scripts stay portable to macOS bash 3.2 and BSD tools.
