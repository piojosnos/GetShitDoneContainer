> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| host test scripts -> Docker Desktop on the Mac | every docker call must aim at the throwaway sbx-hosttest sandbox, never a real sandbox or an old-layout container | container names, labels, compose project |
| agent-authored test code -> the Mac | host scripts run on the Mac; nothing may delete or write outside the run folder | files under the run folder |
| run-all.sh -> the user's Mac | the runner never deletes; it only prints the cleanup command | cleanup command text |
| Coexistence -> old-layout containers | read only (docker ps), one file written in the run folder | container snapshot |
| H-06 -> the user's git identity | the host git call ignores the user's git configuration | git identity (personal data) |
| manual helpers -> the user at a terminal | only files under tests/host/manual/ may read answers or open a tty | y/N answers |
| image build -> /etc/sbx/start.d | root-owned, outside the mount; its entries decide what runs before the agent's command | start hooks (integrity) |
| self-test -> base/sbx-entrypoint | the self-test sources the shipped script; nothing test-only may reach the image | none |
