H-05 (plan 01) is the model of a converted check: the setup lines stay above the first banner, one banner per function, globals for values shared between functions, locals only for loop and scratch variables, Main / Entry Point banner over the calls and one report_check.
Guard constraints: check names in run-all.sh stay literal strings (the guard greps run-all.sh for each check's file name); no read, rm or tty flag on a code line; no planning IDs in comments.
Pitfalls: declare a local on its own line before assigning it; read $? right after the assignment; never call add_problem or stop_check inside a command substitution or a pipeline stage; every variable in a PASS text must be set before report_check runs.
Conventions for every file this plan touches (.claude/CLAUDE.md, ~/.claude/code-conventions.md): braces always; a blank line before and after every if, for, while and case block (else chains stay attached); full variable names (only i, j, k and e are short); ASCII only; no dash used as punctuation in comments (no em or en dash, no spaced double hyphen); no planning or review IDs in source (no D-NN, WR-NN, AR-NN, T-NN, phase numbers, .planning paths); no comment about what the code used to do; host scripts stay portable to macOS bash 3.2 and BSD tools.
