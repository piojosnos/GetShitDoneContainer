### Auto-fixed Issues

**1. [Rule 1 - Bug] Double slash in a guard message**
- **Found during:** Task 1 scratch-copy proof
- **Issue:** The skills loop printed `best-practices/skills/foo//SKILL.md` because the glob keeps its trailing slash.
- **Fix:** Strip the slash (`skillDir=${skillDir%/}`) before use.
- **Files modified:** tests/guard.sh
- **Verification:** Re-ran the planted skill case; the message now prints a single slash.
- **Committed in:** 3375aed (Task 1 commit, fixed before committing)

**2. [Rule 1 - Bug] Empty frontmatter list raised a false FAIL**
- **Found during:** Task 2 (guard design review)
- **Issue:** `bundle_path_globs_are_quoted` reads items through a here-document, which yields one empty line when a file has frontmatter without list items; the empty line would be reported as unquoted.
- **Fix:** Skip empty items.
- **Files modified:** tests/guard.sh
- **Verification:** Guard passes on the real bundle; unquoted-glob plant still fails.
- **Committed in:** ff2155b (Task 2 commit)
