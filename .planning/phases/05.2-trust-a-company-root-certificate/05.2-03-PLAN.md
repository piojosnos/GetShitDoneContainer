## Phase Goal

ROADMAP.md Phase 5.2 goal (verbatim): "A sandbox builds and runs on a Mac behind a company HTTPS proxy (Zscaler) by trusting one optional root certificate file; without the file, the image is unchanged. Runs before 5.1: it blocks every build on the work Mac."

This is the gate of the phase. Everything a Linux check can prove is proven here, the code commits move onto one clean branch cut from origin/main, and the user runs what only real Docker can prove: first on the home Mac (no proxy: the image is unchanged without a root, and the mechanism works with throwaway roots), then on the work Mac (behind Zscaler: the build and the tools reach the network).

Planning notes (each a choice the user can object to at review):
- The Mac runs are `checkpoint:human-verify` tasks with `gate="blocking-human"`, although `workflow.human_verify_mode` is end-of-phase: Docker does not run in the dev sandbox, so an automatic approval would mark the phase verified with nothing run. Every earlier phase ran its Mac gate this way.
- The working branch sits on an older main (before the retirement merge), so the Macs never test it. They test `feat/company-root-certificate`, cut from origin/main, through their tools clone: that is also the clone `sbx-upgrade` builds from. The branch reaches both Macs through GitHub, so step 1 on the home Mac is the user pushing it from this sandbox with one `docker exec` line (the user's own push; Claude never pushes). If the user prefers, they can tell Claude in the orchestrating session to push it instead, before starting the steps.
- The user's Claude terminal cannot copy and paste: the commands go into `/home/sandbox/workspace/mac-steps-cert.txt` (on the Mac `/Users/demian/gsd-workspace/GetShitDoneContainer/mac-steps-cert.txt`), and the home Mac steps `tee -a` into `/Users/demian/gsd-workspace/GetShitDoneContainer/cert-home.log`, which Claude reads at `/home/sandbox/workspace/cert-home.log`. The work Mac is another machine: the user reports its results in words, or copies its two logs into that folder.
- The home Mac run does the research's mechanism proof with a throwaway file of two self-made roots plus a private key, so the Mac's BSD awk, LibreSSL and Docker Desktop are proven before the work Mac, and Claude can read every log.
- A failure becomes input for `/gsd-plan-phase 5.2 --gaps`; the work Mac part does not start until the home Mac part passed.
- Reversibility: records, a local branch and a pushed feature branch; reversible.
