## PR description draft

Title: `feat: trust an optional company root certificate in the image build`

```text
Behind a company HTTPS proxy (Zscaler), the base build stops at the gh
download with "curl: (60) SSL certificate problem": the Mac trusts the
proxy's root through the Keychain, the images do not. This adds one optional
input, SBX_CA_CERT, a PEM file on the Mac. Unset or empty, nothing changes.

What changed
- build.sh reads SBX_CA_CERT. A relative, missing, unreadable or non-PEM
  value is refused before Docker runs (exit 1, a "build.sh: SBX_CA_CERT"
  line). The file is split into one certificate per file in a temp folder,
  keeping only certificate blocks so a private key never reaches the build,
  and passed to the base build as the named context "cacert". A starred
  banner names the file, subjects and fingerprints before the first build
  and after the last.
- base/Dockerfile adds the certificates to the system store before any
  download, then, after the toolchains, to the JDK cacerts, npm, pip, uv and
  interactive Node. Settings are files, not ENV, so an image built without
  the variable is unchanged.
- The supply-chain guard lets the one empty "FROM scratch AS cacert" stage
  through; the pin rule is otherwise unchanged.
- README gains "Behind a company HTTPS proxy": setup steps, what trusts the
  root and how, the trade-off, a known limit and a manual checklist.

What you accept
- The images trust anything the proxy signs. Keep the file to the one root.
- A Node program run by a non-interactive "docker exec" does not get
  NODE_EXTRA_CA_CERTS; run it from sbx-shell.

How it was verified
- Linux: shell syntax of every script, the guard (shellcheck, hadolint and
  the supply-chain rules), the guard, entrypoint and sbx self-tests, and
  dry runs with a fake docker for unset, empty, valid and six bad values.
- Home Mac (no proxy): to be filled in after the run.
- Work Mac (behind Zscaler): to be filled in after the run.
```

The two Mac bullets are filled in with the real results before the user gives the go for the PR.
