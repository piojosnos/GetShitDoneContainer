## Shared Patterns

### One code path, agent name in, texts out
**Source:** `base/selfcheck/best_practices_links.py` (templates + `generated_dir` helper)
**Apply to:** the linker, the check, every test that builds link texts. Init and check share one `clone_failure`, and a unit test pins identical detail and hint; keep it.

### Fail closed with a fix line
**Source:** `best_practices_links.py` lines 63-76 (`failed(problem, hint)`)
**Apply to:** missing clone, old-layout clone. Clone failure leaves `config_dir` untouched (tests assert `list(config1.iterdir()) == []`).

### Own-link root is the whole clone
**Source:** `is_best_practices_link(link, target_root)` lines 28-39 (lexical, no resolve)
**Apply to:** rules `_place_link`, `_link_skills`, `_remove_stale_links`, `_stale_link_problem_list`. Pass `best_practices_dir`.

### Per-agent data in `AgentSpec`, not in scenarios
**Source:** `tests/integration/agent_specs.py`
**Apply to:** the relink and first-run scenarios.

### Project style
ASCII only; no planning IDs or "was X" comments in source; collection names with shape suffix (`skill_name_list`, `clash_list`); blank line around `if`/`for`; member-separator rules between functions.
