## Conventions carried into every edit

- Host-side shell (tests/, build.sh, clean.sh) is stock macOS bash 3.2 with BSD tools: no `sed -i`, `grep -P`, `readlink -f`, `date -d`, `stat -c`, `mapfile`, `declare -A`; `sed -E` with `#` delimiters.
- Braces always, a blank line before and after every if/for/while, full variable names, collection names ending in List/Set/Map, ASCII only, no planning IDs (decision, cut or criterion IDs, phase numbers, `.planning`) in code, comments or docs, no dashes as punctuation, punctuation outside closing quotes.
- New files use the comment shape of D-11 and D-12: a rule line is `#`, a space and 78 hyphens (80 columns) at column 0; a banner is rule, one title line of at most 80 columns, rule; an optional "why" block of at most two lines follows and is closed by a rule; the file header right after the shebang is the same shape with the purpose as title and at most two lines (usage plus one other). Existing files keep their current style here; plans 05 to 09 convert them.
- In the agent tool shell `grep` is a function that runs ugrep; verify commands use `command grep` so they run GNU grep, as the scripts do.
