## Phase Goal

ROADMAP.md Phase 2.1 goal (verbatim): "The repo carries only the shell one person can maintain. About 620 lines of shipped scripts do the work; the checks around them shrink to what protects the images and the sandbox."

The goal line is not in user-story form; it is quoted verbatim as in earlier phases.

This slice finishes SC3: the 25 older host checks and Coexistence get the schematic header and banners, so every check opens with what it proves and what it needs, in one screen. The Mac run behaviour does not move.

Planning notes:
- Measured on 2026-10-13: the checks hold about 660 comment lines, about 160 of them over 80 columns; all carry both a `# Depends on:` and a `# Needs:` line. D-12 allows the title plus two lines, so `# Needs:` stays and `# Depends on:` goes (the runner's prose no longer refers to it after plan 08).
- The tasks touch eight or nine files each on purpose: the edits are comment lines only, mechanical and checked by the comment-only diff; splitting further would add plans without adding safety.
- Where a check's header bullets carry a fact a reader needs and no doc states (for example H-18's fake API and its tie to the pinned Claude, H-25's bare-build log names, H-17's network-off start), that fact moves into the banner of the function that acts on it, two why lines at most.
- Reversibility: comments only; reversible.
- Spec-less probe fallback skipped: no requirement IDs to probe, no SPEC.md (visible, recorded choice).

## Conventions carried into every edit

- Comments say only why; delete comments that restate the code; no "was X" history; no planning IDs (decision, cut or criterion IDs, phase numbers, `.planning`, review finding IDs; host check IDs such as H-09 are code names and stay); ASCII only; no dashes as punctuation; punctuation outside closing quotes.
- Messages printed by `add_problem`, `report_check`, `echo` and heredocs are code: do not change them.
- In the agent tool shell `grep` is a function that runs ugrep; verify commands use `command grep`.

## Checks used in every task

- Comment-shape scan over the task's files: no rule line other than exactly `#`, a space and 78 hyphens; no comment line over 80 columns; no three non-rule comment lines in a row.
- Header check: each file has exactly one line starting `# Needs: ` and no line starting `# Depends on:`.
- Comment-only diff: the task's change (uncommitted, or the task commit once committed) adds or removes only comment and blank lines, and is not empty.
- bash -n and shellcheck at `-S warning` (rehearsal binary) print nothing for the task's files. Rebuild `${TMPDIR:-/tmp}/sbx-linters/bin` from the approved rehearsal rows of 02.1-PINS.md if it is gone.
