## Conventions carried into every edit

- Host-side shell is stock macOS bash 3.2 with BSD tools (no `sed -i`, `grep -P`, `readlink -f`, `mapfile`, `declare -A`); braces always, blank lines around control flow, full variable names, ASCII only, no planning IDs in code or comments, no dashes as punctuation.
- Comment shape (D-11, D-12) for every banner this plan writes or rewrites: rule line = `#`, a space and 78 hyphens (80 columns) at column 0; banner = rule, one title line (at most 80 columns), rule; optional why block of at most two lines, closed by a rule; the file header right after the shebang has the same shape (purpose title; usage plus at most one other line). A file this plan rewrites as a whole (both run-all.sh runners of the self-tests and the guard runner) is left fully in this shape.
- In the agent tool shell `grep` is a function that runs ugrep; verify commands use `command grep`.
