## Phase Goal

## Conventions carried into every edit

- Host-side shell is stock macOS bash 3.2 with BSD tools; `docker` calls get `</dev/null`; braces always, blank lines around control flow, full variable names, ASCII only, no planning IDs, no dashes as punctuation.
- Comment shape (D-11, D-12): rule line = `#`, a space and 78 hyphens (80 columns) at column 0; banner = rule, one title line (at most 80 columns), rule; optional why block of at most two lines, closed by a rule; file header right after the shebang in the same shape. H-26 and tests/guard/isolation.sh are written whole in this shape; sandbox-rules.sh banners this plan touches get it too.
- Host check header (D-12): title `H-26: ...`; the comment block holds `# Needs: test sandbox running` and at most one other line. No `# Depends on:` line (it is being dropped from every check).
- In the agent tool shell `grep` is a function that runs ugrep; verify commands use `command grep`.
