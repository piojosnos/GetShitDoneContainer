## Notes for the reviewer

- No npm, PyPI or crates package is added, so the package-legitimacy check does not apply.
- The images are pinned as tag plus index digest, so every machine and architecture pulls the same bytes. On the Mac you can compare: `docker buildx imagetools inspect koalaman/shellcheck:v0.11.0` and `docker buildx imagetools inspect hadolint/hadolint:v2.15.1`; the Digest line must equal the digest in the Value cell.
- The two binaries add about 115 MB to sbx-base (55 MB for shellcheck, 60 MB for hadolint).
- apt has an older shellcheck and no hadolint, and apt packages are unpinned by policy, so apt is not used.
- The rehearsal rows are separate from the image rows. Rejecting a rehearsal row does not stop the phase: later plans then skip the in-sandbox lint runs and rely on the Mac run.
- GSD comes only from @opengsd/gsd-core; nothing in this table touches it.
