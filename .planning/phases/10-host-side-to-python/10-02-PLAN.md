<objective>
Port the four everyday commands onto the JSON registry: `sbx-add` with the overlap check that resolves both paths (HOST-03), and `sbx-start`, `sbx-stop` and `sbx-shell` with the Compose call built by one pure function. Each command keeps its name, its wording and its exit codes; each becomes a two-line launcher.

Purpose: these are the commands a user types daily; the overlap rule is the isolation guarantee between sandboxes.
Output: `sbx/overlap.py`, `sbx/add.py`, the Compose layer of `sbx/docker.py`, `sbx/start.py`, `sbx/stop.py`, `sbx/shell.py`, four launchers, their unit tests; the bash groups for these commands deleted.

</objective>
