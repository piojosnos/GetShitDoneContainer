Design choices made here (Claude's discretion; flag them in the SUMMARY):
- The approved sketch was `sbx-run-agent NAME [args]`. The shared script cannot see which wrapper exec'd it (exec replaces the wrapper, and a script's $0 is its own path), so to keep the refusal naming the wrapper, the wrapper passes its own name first: `sbx-run-agent WRAPPER AGENT [agent arguments]`. Deriving the wrapper name from the agent name would need a per-agent mapping in a base script, which the architecture rules forbid.
- The approved sketch passed loose strings (list name, owner text, pass word) to three functions. The load-failure text also differs ("not a list of steps" vs "not a list of checks"), so the words that differ between the runners are bundled in one frozen dataclass, StepFileKind, with one constant per runner. This mirrors the ImageRules dataclass in base/selfcheck/image_ownership.py.
