## Choices to confirm on the PR threads

1. **Signature `sbx-run-agent WRAPPER AGENT [agent arguments]`** (the approved sketch was `NAME [args]`). The shared script cannot see which wrapper exec'd it, and deriving the wrapper name from the agent name would need a per-agent mapping in a base script. So each wrapper passes its own name first: `exec sbx-run-agent sbx-claude claude "$@"`. The refusal text is unchanged, so the README troubleshooting row and H-27 stay valid.
2. **`StepFileKind` frozen dataclass** instead of loose strings (list name, owner text, pass word). The load-failure wording also differs ("steps" vs "checks"), so five fields (`list_name`, `item_word`, `module_prefix`, `owner_text`, `pass_word`) travel together, one constant per runner (`_FILE_KIND`). It mirrors `ImageRules` in `image_ownership.py`.
