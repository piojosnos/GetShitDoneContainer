## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The old guard sources tests/guard/lib.sh between Task 1 and Task 3**
- **Found during:** Task 1
- **Issue:** The plan says every helper and the other constants stay in tests/guard.sh until Task 3, while lib.sh must already hold the shared constants and helpers for the new groups. rules.sh requires every function and constant to be defined exactly once and runs after Task 2, so duplicated copies would print DUPLICATE.
- **Fix:** In Task 1 the old file dropped its copies of the shared constants, `nowhere_matches`, `has_line` and `frontmatter_of` and loaded tests/guard/lib.sh with one dot-source line; the one-group helpers and constants moved with their groups in Tasks 2 and 3. The old file ran the remaining rules unchanged and prove.sh stayed identical at each step.
- **Files modified:** tests/guard.sh (removed in Task 3)
- **Verification:** prove.sh `same: guard (23 PASS)` after each task; rules.sh reports no DUPLICATE
- **Committed in:** `ba9bf32`

**2. [Rule 3 - Blocking] The bundle dash rule's comment quotes a spaced double hyphen**
- **Found during:** Task 3 (layout lint check 9, dash as punctuation in a comment)
- **Issue:** The original comment `(em dash, en dash, " -- ", " - ")` contains the spaced double hyphen the lint flags.
- **Fix:** The comment now says `(em dash, en dash, double hyphen, or a lone hyphen between spaces)`. The rule body, which holds the literal check, is unchanged.
- **Files modified:** tests/guard/bundle-content.sh
- **Verification:** layout-lint clean; rules.sh `same: bundle_has_no_dash_punctuation`
- **Committed in:** `65e0288`

**3. [Rule 2 - Missing critical] rules.sh excludes the runner's FAILS counter from the constant check**
- **Found during:** Task 2
- **Issue:** The baseline has a column-0 line `FAILS=0` in its runner. It is not a constant: run_rules and run-all.sh keep their own counters, so requiring it to appear once would always report MISSING.
- **Fix:** rules.sh skips that one name and says why in a comment.
- **Files modified:** harness/rules.sh
- **Committed in:** `40aedbe`
