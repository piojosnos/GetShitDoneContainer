# Phase 01.4 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Plain bash suites (no external framework); `bash -n` for syntax |
| **Config file** | none |
| **Quick run command** | `bash tests/guard/run-all.sh && bash tests/selftest/entrypoint/run-all.sh` |
| **Full suite command** | `bash tests/guard/run-all.sh && bash tests/selftest/entrypoint/run-all.sh && bash tests/selftest/bundle/run-all.sh && bash tests/selftest/host/run-all.sh` |
| **Layout lint** | `bash .planning/phases/01.4-test-suite-refactor/harness/layout-lint.sh` (prints `layout-lint: clean`) |
| **Estimated runtime** | ~40 seconds (guard and entrypoint under 1 s, bundle about 6 s, host about 30 s) |

**Failure looks like:** a line starting `FAIL:`; a final `N case(s) failed.` or `N rule(s) broken.`; non-zero exit; any `LINT:` or `SYNTAX:` line. A bundle `SKIP:` line is not a pass.

---

## Sampling Rate

- **After every task commit:** `bash -n` on touched files, plus the touched suite's `run-all.sh`
- **After every plan wave:** full suite command, layout lint, and the name-list diff from the proof harness
- **Before `/gsd-verify-work`:** full suite green, proof harness clean (name lists, rule bodies, mutation comparisons), stale-reference greps empty, and the user's Mac run of `bash tests/host/run-all.sh`
- **Max feedback latency:** 60 seconds
