## Phase Goal

ROADMAP.md Phase 2 goal (verbatim): "The sandbox has the full development toolchain plus Claude Code, GSD, and ccusage baked into the image at versions pinned in one `versions.env`. Rebuilding with changed pins delivers the new versions into the sandbox while login and history persist."

This plan delivers the first half of success criterion 4: the image's `@opengsd/gsd-core` is synced into the persisted `~/.claude` at every start, offline, with no `npx` or `@latest` in the start logs. Plan 06 proves the "image wins and spares the user's files" half.

Planning notes:
- Research verified the installer on arm64 Node 24: offline, no child process, idempotent, preserves settings keys, credentials, `.claude.json` and `projects/`, backs up local edits to `gsd-local-patches/`. It hangs (does not fail) on an uncreatable folder such as /proc/no-such-dir, which H-17 uses to provoke a failing hook; the hook therefore makes the folder first (research Pitfall 1).
- Planning check run on 2026-10-08 with gsd-core 1.15.0: the installer removes a skills/gsd-* folder that GSD does not ship (H-16's planted `gsd-h16-sample` would vanish). Plan 06 changes H-16 and the docs for this; this plan does not touch H-16.
- The hook compares the synced `gsd-core/VERSION` with `gsd-tools runtime-identity --raw` (0.2 s, no network, no file written in HOME, checked on 2026-10-08), so a silently stale GSD cannot pass a start (D-13).
- The hook text must pass `no_installs_at_container_start`: none of the words that rule bans may appear in it, comments and messages included.
- The fake docker now runs every real hook in name order (as the entrypoint does), with a fake `gsd-core` and `gsd-tools` on PATH. The fake GSD models only what the checks read: VERSION, one GSD skill, settings.json, the identity line.
- Reversibility: GSD writes into every sandbox's persisted state/claude at each start (settings.json merge, gsd-* skills). This was decided by the user (D-12); undoing it means running GSD's own uninstall in each sandbox, so it is rated costly and flagged, not gated.
