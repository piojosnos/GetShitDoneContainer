## Phase Goal

ROADMAP.md Phase 2 goal (verbatim): "The sandbox has the full development toolchain plus Claude Code, GSD, and ccusage baked into the image at versions pinned in one `versions.env`. Rebuilding with changed pins delivers the new versions into the sandbox while login and history persist."

The roadmap marks this phase `mvp`, but the goal line is not in user-story form. As in the earlier phases it is quoted verbatim here; run `/gsd-mvp-phase 2` if a user story is wanted.

This plan is the phase tracer: the pins that exist today (Node, gh, Claude Code, Ubuntu by tag) move into `versions.env` and travel through `build.sh` into both Dockerfiles and into the host tests. No new package is installed by this plan; new pins arrive only after the approval in plan 02.

Planning notes:
- `versions.env` keeps `UBUNTU_IMAGE=ubuntu:24.04` by tag in this plan, exactly what is built today. The digest needs the plan 02 approval (D-07, D-11); plan 03 adds it and makes the guard require it.
- D-04 is followed as written: `set -a; source ./versions.env; set +a` and `grep -oE '^[A-Z_]+' versions.env` for the names. The only change to the snippet is `./` in front of the file name, so bash never searches PATH for it. Pin names are therefore uppercase letters and underscores only; the guard checks that.
- No `# syntax=` line: it would make BuildKit pull a Dockerfile frontend image by a moving tag at every build. The `# check=skip=InvalidDefaultArgInFrom` directive works with the frontend built into Docker Desktop (Mac assumption, recorded in plan 09).
- build.sh puts extra arguments right after `docker build`, so `./build.sh --no-cache` logs as `build --no-cache -f ...`; the existing runner-failures case for the no-cache rebuild keeps working unchanged.
- Task 1 touches twelve small files on purpose: moving the pins breaks the guard, the host library, the fake docker and three self-test groups in the same step, and the tracer must leave every suite green.
- Reversibility: build.sh and versions.env are repo-internal; Phase 3 will call build.sh. Rated reversible.
