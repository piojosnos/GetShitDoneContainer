## Phase Goal

ROADMAP.md Phase 1 goal (quoted verbatim, not rewritten): "The user can run a Claude Code sandbox on their Mac. Code lives in `<sandbox>/workspace` and Claude state lives in `<sandbox>/state/claude`. Nothing is mounted over `/home/sandbox`, and the Claude login survives recreating the container and rebuilding the image."

MVP note: the ROADMAP `**Goal:**` line is not in "As a / I want to / so that" form. Per the MVP rules no story is invented here. Run `/gsd-mvp-phase 1` if you want the goal line converted. The slices below do not depend on the wording.

<objective>
Deliver the thinnest real Claude sandbox, end to end: a shared base image, a Claude image FROM it, and a compose file that mounts `$SBX_DIR/workspace` and `$SBX_DIR/state/claude`. The user can build, start, exec into it, and log in to `claude` with the login stored on the Mac. A static check proves the wiring without Docker, and a quick-start doc gives the documented `docker compose` command.

- Deviation from RESEARCH.md Pattern 4 (planner finding): GNU `install -d -o sandbox -g sandbox /home/sandbox/.local/state/sbx/...` sets the owner only on the named leaf directories.
