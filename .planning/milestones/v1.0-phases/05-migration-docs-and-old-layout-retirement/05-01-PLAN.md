## Phase Goal

ROADMAP.md Phase 5 goal (verbatim): "The user's existing sandboxes run on the new layout with login and history intact. The repo contains only the new layout, and the README describes exactly what exists, including its security limits."

The roadmap marks this phase `mvp`, but the goal line is not in user-story form; it is quoted verbatim as in earlier phases (run `/gsd-mvp-phase 5` if a story is wanted).

This plan is the phase tracer. Task 1 makes `README.md` the one main doc and keeps the guard green (the thinnest path through docs, references and guard rules). Task 2 points every other reference at it. Task 3 delivers the thing the user waits for: `MIGRATION.md`, a recipe they paste to move one old sandbox, proven here by a dry run on a fake old home. Plan 02 rewrites the README, plan 03 is the Mac gate with the first real migration, plan 04 retires the old layout after the user confirms, plan 05 is the final gate.

Planning notes (each a choice the user can object to at review):
- D-09 names `cc-down` for the stop step. The recipe stops the old container with `docker stop "cc_gsd_$PROJECT"` instead, so the old sandbox stays runnable as the rollback (D-06): `ClaudeCode/cc-down.sh` runs `docker-compose -p cc_NAME down -v`, which deletes the container (the old README says so), and the retirement later deletes the script from the repo. The order of D-09 is unchanged.
- D-07 lists four values. A fifth set-once value, `PROJECT` (the name given to `cc-up.sh`, so the container is `cc_gsd_$PROJECT`), lets the stop and undo commands paste unchanged, which is what D-07 is for. `ENC` is derived, not typed.
- D-08 writes the history folder as `-home-sandbox-$CODE` and asks research to confirm the encoding. Research confirmed Claude Code replaces every character other than a letter or digit with `-`, so the recipe derives `ENC` (`GSD_StaticSiteGenerator` would be `GSD-StaticSiteGenerator`).
- Research found two path-keyed items D-08 does not list: the `.claude.json` `projects` key and `githubRepoPaths`, and the `project` field in `history.jsonl`. They get one optional step (without it Claude asks once to trust the folder and per-project settings start empty). Research also found the old `.gitconfig` names `/usr/bin/gh`, which the new image lacks, so the copy rewrites that path.
- D-12 asks for an extra section for this repo's own sandbox. The tools clone itself is set up first, in "Once: the tools clone", because every `sbx-add` of the move runs from it; the closing section covers what is special about this repo's sandbox.
- Copy/paste blocks carry no `#` comments: zsh, the Mac's default shell, does not treat `#` as a comment at the prompt, so a trailing comment would turn an assignment into a failed command. Explanations sit in bullets and tables next to each block. A block whose command waits for input (sbx-shell, sbx-claude, sbx-rm) holds that command last, so pasted lines never become its input.
- Reversibility: reversible (docs, two guard file lists and five comment or message lines; one commit each).
