### `claude/start.d/10-best-practices` (start hook, file-I/O)

**Analog:** itself, `claude/start.d/10-best-practices` (85 lines). Keep the banner, `set -eu`, function-plus-`Main / Entry Point` layout.

**Banner and header** (lines 1-11):
```bash
#!/usr/bin/env bash
# ------------------------------------------------------------------------------
# Syncs the image's best-practices bundle into the Claude config at every start
# ------------------------------------------------------------------------------
# Other skills (GSD, your own) are never touched.
# ------------------------------------------------------------------------------
set -eu

bundleDir=${SBX_BUNDLE_DIR:-/opt/sbx/best-practices}
configDir=${CLAUDE_CONFIG_DIR:-}
skillList=$configDir/.best-practices-skills
```
Change: `bundleDir=${SBX_BUNDLE_DIR:-}` (no `/opt` default; ENV supplies the clone path).

**Error line format** (lines 16-26): `[sbx] ERROR: ...` to stderr, `exit 1`. Keep for empty `CLAUDE_CONFIG_DIR`/`SBX_BUNDLE_DIR`; drop the "bundle missing" failure (a missing clone is a one-line `echo` and exit 0).

**Manifest-driven removal, keep as is** (lines 41-55):
```bash
remove_listed_skills() {
  local oldName

  if [ ! -f "$skillList" ]; then
    return
  fi

  while IFS= read -r oldName; do
    case "$oldName" in
      ""|*/*|.*) continue ;;
    esac

    rm -rf "$configDir/skills/$oldName"
  done <"$skillList"
}
```

**Copy loop becomes link loop** (lines 60-76): `cp -R "$skillDir" ...` becomes `rm -rf` then `ln -s "../../../best-practices/skills/$skillName" "$configDir/skills/$skillName"`; `sync_rules` (`rm -rf` + `cp -R`) becomes `rm -rf` + `ln -s ../../best-practices/rules "$configDir/rules"`. Never `ln -s` over an existing link (nests inside the clone). The full validated skeleton is RESEARCH.md Pattern 1; copy it.

**Main block** (lines 78-85): `check_inputs`, `mkdir -p "$configDir/skills"`, then remove, then link; branch on `[ -d "$bundleDir/rules" ]`, else `echo "[sbx] no best-practices clone at $bundleDir; run sbx-bundle-clone"`.

## Shared Patterns

### Script banner and layout
**Source:** `claude/start.d/10-best-practices` lines 1-7 and 78-85.
**Apply to:** all three `claude/bin/` wrappers, the rewritten hook, the new selftest. 80-column rule lines, title, `set -eu` (tests use `set -u`), functions, `# Main / Entry Point`. Braces always, blank line before and after control flow, full variable names, `xList` suffix for collections.

### Error and log lines
**Source:** `claude/start.d/10-best-practices` lines 17-25.
```bash
echo "[sbx] ERROR: CLAUDE_CONFIG_DIR is not set." >&2
exit 1
```
**Apply to:** every new script. Info lines are `echo "[sbx] ..."`.

### Pin must be set or the build fails
**Source:** `claude/Dockerfile` lines 43-44.
**Apply to:** `BUNDLE_REPO_URL` ARG.

### Test reporting
**Source:** `tests/host/h14-bundle-in-image.sh` (`add_problem`, `first_lines`, `report_check`, `require_test_sandbox`) and `tests/selftest/entrypoint/gsd-hook.sh` (`expect "<name>" <matcher> ...`).
**Apply to:** all host tests and selftests.

### macOS portability
Host tests (`tests/host/*`, `host-test.sh`) run on bash 3.2 and BSD tools: no `readlink -f`, `sed -i`, `stat -c`, `find -printf` there. In-container probes (like h14's `find -printf` inside `in_container`) run on GNU and are fine.

### Source hygiene
No planning IDs (phase, D-xx) in committed source, fixtures, comments. ASCII only. No em/en dashes or `--` as punctuation.
