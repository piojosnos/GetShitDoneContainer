## Decisions Made

- **H-00 "major 2 or higher".** Compose releases moved from 2.x to 5.x in 2025, so "major equals 2" would wrongly fail current Docker Desktop. The check strips a leading `v`, reads the major number, and fails only below 2 or when `docker compose version` itself fails.
- **Guard negative proof.** In a scratch copy of the repo (outside the working tree), `tests/host/h04-nonroot-user.sh` was copied to `tests/host/h98-neg.sh` with `H-04` renamed and `docker rmi sbx-claude:local` appended, then `bash tests/guard.sh` was run there. Output:
  ```
  PASS: host_tests_are_portable
      tests/host/h98-neg.sh:19:docker rmi sbx-claude:local
  FAIL: host_tests_never_delete
  PASS: host_tests_are_unattended
  ```
  A second scratch file proved the other rules: `rm -rf`, `docker volume rm`, `docker compose down -v`, `read -r`, `docker exec -it`, `mapfile`, `stat -c` on the host, a planning ID, `sbx-demo`, `SBX_NAME=demo`, `cc_foo`, a missing Depends on line and a missing runner entry each tripped their rule; `docker run --rm`, `docker volume ls`, `stat -c` inside `in_container`, the printed `rm -rf %q` line and comment lines mentioning `read` or `rm` did not.
- **Strict `SBXTEST_DIR`.** If it is set but not an existing folder named `sbx-hosttest-*`, `RUN` stays empty and a reason goes to stderr; the container mount is not used as a silent fallback.
- **Cleanup line exemption.** The never-delete rule exempts only lines containing `rm -rf %q`, the printed cleanup in `print_next_block`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] run_timeout watcher left a long sleeping orphan**
- **Found during:** Task 1 (designing `run_timeout` from the research pattern)
- **Issue:** Killing the watcher subshell does not kill its `sleep 120` child. The orphan would keep the stdout pipe of any caller that captures output (for example the self-test, or a user piping the runner to `tee`) open for up to 120 seconds, so the run would appear to hang after the summary.
- **Fix:** The watcher polls once a second with `kill -0` and exits as soon as the command finishes; its output is redirected to `/dev/null`. Timeout behavior (return 143) is unchanged.
- **Files modified:** `tests/host/lib.sh`
- **Verification:** self-test finishes in about a quarter of a second; healthy run exits 0
- **Committed in:** `91a1549`

**2. [CLAUDE.md-driven] No Co-Authored-By trailer on commits**
- **Found during:** Task 1 commit
- **Issue:** The dispatch note asked for a `Co-Authored-By` line, but the user's saved rule for this project says no AI attribution lines in commits (it overrides the harness default).
- **Fix:** The first commit was amended to drop the trailer before anything was pushed; all four commits carry none.
- **Files modified:** none
- **Committed in:** `91a1549` (amended)
