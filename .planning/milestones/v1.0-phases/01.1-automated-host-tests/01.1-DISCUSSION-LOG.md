## Throwaway sandbox

| Option | Description | Selected |
|--------|-------------|----------|
| `mktemp` folder | Under `$TMPDIR`, shared by Docker Desktop by default | ✓ |
| Delete everything at the end | Remove container and folder automatically | |
| Keep folder on failure | Keep it for debugging, despite test credentials inside | |

**User's choice:** Use `mktemp` with a sensible prefix and a timestamp or random suffix. Never delete anything on the filesystem; print the delete command at the end (pass or fail) to copy and paste. Containers and images may be deleted by the scripts.
**Notes:** Follow-up: a leftover test container blocks the fixed name on the next run. Options were "refuse and print cleanup" or "unique container name per run". Resolved by the user allowing container removal: the runner removes the leftover test container itself.
