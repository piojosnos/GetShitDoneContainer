## Pattern Assignments

### `base/sbx-entrypoint` (entrypoint, ordered hooks)

**Analog:** itself (`base/sbx-entrypoint`).

**Style to match** (lines 1-16 header comment bullets; `set -eu`; `die()` lines 22-26; loop lines 36-40):
```bash
die() {
  echo "[sbx] ERROR: $1" >&2
  echo "[sbx]        Start the sandbox with 'docker compose up' (see SANDBOX.md)." >&2
  exit 1
}
...
# ${SBX_STATE_DIRS:-} is unquoted on purpose: one word per folder name.
for d in shell gh git ${SBX_STATE_DIRS:-}; do
  mkdir -p "$state/$d"
done

exec "$@"
```
**Insert** the RESEARCH "Hook loop" block between the `done` and `exec "$@"`. Do NOT call `die()` for hook failure (its compose hint is wrong); print `[sbx] ERROR: start hook $hook failed; ...` directly. Add a bullet to the header comment about start hooks.

**Guard traps** (`tests/guard.sh` rule `no_installs_at_container_start`, line ~99): regex `\b(npm|npx|bunx|pip|apt-get|apt|curl|wget)\b` is applied to comments too; also `:latest|@latest` is banned. Keep new comment words clear of these.

### `tests/guard.sh` (static test)

**Analog:** itself.

**Helper to reuse** (lines 28-34): `nowhere_matches REGEX FILE...` prints offenders and returns 1; `has_line FILE LINE`.
```bash
nowhere_matches() {
  local regex=$1; shift
  local hits
  hits=$(grep -En -- "$regex" "$@" 2>/dev/null)
  [ -z "$hits" ] && return 0
  echo "$hits" | sed 's/^/    /'
  return 1
}
```
**Rule shape** (line ~182):
```bash
host_tests_have_no_planning_ids() {

}
```

## Shared Patterns

### Fail-fast start errors
**Source:** `base/sbx-entrypoint` lines 22-26 (`die`) and the hook loop.
**Apply to:** the hook loop and anything the sync script can fail on. Use the `[sbx] ERROR:` prefix; skip the compose hint for hook failures.

### Image owns files outside the mount, root-owned
**Source:** `base/Dockerfile` Entrypoint section (`COPY` while root, `chmod`), `claude/Dockerfile` lines 14-21.
**Apply to:** bundle, hook, managed settings. Never `chmod a-w` the synced copies (host cleanup `rm -rf` would fail).

### Dockerfile comment style
**Source:** `base/Dockerfile` section blocks: `# --- Section ---` then `# - reason` bullets above the RUN/COPY.
**Apply to:** every new Dockerfile block.

### Host check skeleton
**Source:** `tests/host/h13-env-and-no-self-update.sh` and `h12`.
**Apply to:** H-14 to H-18 (header with `# Depends on:` and `# Needs:`, `set -u`, `lib.sh`, `host_init`, `require_test_sandbox`, `set --` problem list, `fail`/`pass`, `exit`).

### Static guard rule
**Source:** `tests/guard.sh` `nowhere_matches`, runner `for rule in` list.
**Apply to:** all bundle and hook static checks.

### Code and prose conventions
**Source:** `~/.claude/code-conventions.md` and `AGENTS.md` prose rules.
**Apply to:** all new shell (braces, blank lines around control flow, full names, ASCII only), all docs and bundle text (no dash punctuation, punctuation outside closing quotes), no phase or decision IDs in committed source.
