## Decisions Made

- Four exact Edit entries and nothing else, as planned. Write and NotebookEdit entries are accepted by Claude but never consulted, so the guard rejects them rather than letting them give a false sense of cover.
- Owners and modes are read with `find ... -printf` inside the container instead of `stat -c`. Same data, and it keeps the host-side portability rule (no `stat -c` outside `in_container`) free of an exception for the probe's multi-line script.
- The guard's JSON parse is skipped with a note line when `node` is missing, so the rule still works on a host without node.

**2. [Rule 3 - Blocking] `find -printf` instead of `stat -c` in the probe**
- **Found during:** Task 1 (H-14)
- **Issue:** The portability rule only exempts `stat -c` on lines that contain `in_container` or `docker exec`; a multi-line probe script puts it on a line of its own.
- **Fix:** `find "$probePath" -maxdepth 0 -printf 'OWNER %p %u:%g %m\n'` prints the same owner:group and octal mode.
- **Files modified:** tests/host/h14-bundle-in-image.sh
- **Verification:** probe script passes `sh -n` and runs under `sh` on Linux; `bash tests/guard.sh` holds.
- **Committed in:** b211708
