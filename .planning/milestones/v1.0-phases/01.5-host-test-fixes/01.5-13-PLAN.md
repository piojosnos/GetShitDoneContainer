## Phase Goal

ROADMAP.md Phase 01.5 goal (verbatim): "The known bugs in the host tests and the entrypoint, found by the Phase 1 and Phase 1.1 code reviews, are fixed and each fix is proven on the Mac. Kept out of Phase 1.3 so that identical output stays the proof of a safe restructure, and placed after Phase 1.4, which settled that the host checks run on the Mac. From the Phase 1.3 discussion."

Gap closure: D-16 folds three warnings of this phase's code review into the gap closure, because each one weakens whether a green run can be trusted: H-10 passes on any failed start, run_timeout waits forever on a command that ignores SIGTERM, and reset_state can run rm -rf on /state and /tmp.

Planning notes:
- Spec-less probe fallback skipped (no requirement IDs; visible skip).
- Depends on plan 12 only because both change tests/selftest/host/support/fake-docker; the work itself is independent.
- run_timeout design (Claude's discretion in the details, D-16 fixes the escalation): the pid list is collected before the first signal, because children are re-parented once their parent dies and a list taken later can miss them. The watcher polls once per second up to the grace and sends SIGKILL to the same list only when something is still alive. The main shell, after `wait` on the command, waits for the watcher when the status is 143 or 137 (the watcher may be in its grace loop; it ends within 1 s when it never fired, because its countdown sees the command gone, and within the grace when it did). On any other status it stops the watcher at once, as today, so a quick command stays quick.
- The grace is a local in run_timeout (5 s), because lib-sandbox.sh defines functions only.
- H-10 regex: the review's `does not exist|no such file|bind source`, case-insensitive. Mac-only assumption M4 for the final run: the refused start prints moby's "bind source path does not exist" on Compose 2.40 with create_host_path false. If the Mac shows another text, H-10 FAILs with the last output lines in its detail, and that line is the evidence.
- FAKE_UP_RC cannot drive the new H-10 case: the fake reaches its missing-folder branch first, and FAKE_UP_RC would also break the restart of the real sandbox. A new FAKE_H10 value, other, models a start on the missing folder that fails for a reason that is not the folder (a missing image, a time limit).
- The reset_state red case replaces rm and mkdir with shell functions that only record their arguments, inside a subshell, so the red commit never deletes anything.
- Mac-only note M5: the SIGKILL step runs on macOS bash 3.2 (builtin kill with -0 and -9). No check is expected to reach a time limit, so a green Mac run shows only that nothing regressed.
- Reversibility: library internals behind an unchanged interface, one check's verdict, one self-test helper; reversible.
