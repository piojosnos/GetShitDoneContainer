## Accomplishments

- snapshot_old_containers captures docker ps into a variable first and returns 1 when it fails; the filter line `grep -E '^[0-9a-f]+ cc_'` is byte for byte unchanged, so the guard's old-name rule still exempts it.
- snapshot_old_folders prints `git rev-parse HEAD:ClaudeCode HEAD:OpenCode` and then the git status of both folders; it returns 1 when either git call fails.
- record_old_layout in run-all.sh: a failed docker ps is `FAIL: SETUP docker ps failed; the old containers cannot be recorded` and no check runs; a failed git is an INFO line; each snapshot is captured first, then written, so a failure never leaves a partial baseline.
- Coexistence finds each baseline separately and prints which comparison it made: "container and folder snapshots", "container snapshot and git", "folder snapshot and no container baseline", or "git only; no baseline". It compares by content, writes logs/old-containers.after and logs/old-folders.after, and reports "docker ps failed; the old containers could not be compared" and "git could not read ClaudeCode/ and OpenCode/" as problems. With no folder baseline it keeps today's git-status check.
- H-09 list_test_volumes runs `docker volume ls -q --filter label=com.docker.compose.project=sbx-hosttest` with stdin closed and stderr merged; a failed list before or after the rebuild is reported as "docker volume ls failed" and the comparison is skipped.
- H-13 check_no_share_folder uses a case on the exec status: 0 fine, 1 "exists in the container home", anything else "could not check ~/.local/share/claude (docker exec exit N)".
- Fake docker: FAKE_PS_FAIL, volume ls flag parsing (-q accepted, only the sbx-hosttest project filter handled, anything else unhandled) with FAKE_UNRELATED_VOLUMES_AFTER_BUILD listed only when the list is not scoped, and FAKE_EXEC_RC for the share folder test. All off by default.
- New cases: five in the Coexistence group (a scratch git repo helper that reads no user git configuration), three in the runner groups, two each in the H-09 and H-13 groups.
