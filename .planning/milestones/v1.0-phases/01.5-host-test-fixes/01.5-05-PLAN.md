## Phase Goal

ROADMAP.md Phase 01.5 goal (verbatim): "The known bugs in the host tests and the entrypoint, found by the Phase 1 and Phase 1.1 code reviews, are fixed and each fix is proven on the Mac. Kept out of Phase 1.3 so that identical output stays the proof of a safe restructure, and placed after Phase 1.4, which settled that the host checks run on the Mac. From the Phase 1.3 discussion."

Planning notes:
- Spec-less probe fallback skipped (no requirement IDs; visible skip).
- These three are named in ROADMAP SC1: Coexistence false FAIL and false PASS, the flaky H-09 volume compare, H-13 treating any exec failure as success.
- Design choice (discretion): the folder snapshot uses `git rev-parse HEAD:ClaudeCode HEAD:OpenCode` (tree hashes) rather than HEAD itself, so a commit the user makes elsewhere during a long run is not a false FAIL, while a committed change to the old folders is caught.
- Design choice: a failed docker ps at the start is fatal (Docker answered docker info a moment earlier, so it is a real fault); a failed git at the start is not, because one check should not block the other eighteen; Coexistence reports it at the end.
- Research note on the Mac: the user's Mac git once listed files as modified in a code worktree while the sandbox showed it clean. With before and after snapshots that is no longer a false FAIL, as long as nothing changes during the run.
- Mac-only assumption A4: the Compose label is set on the project's volumes. The one-mount check remains the real proof that no volume is used.
- Reversibility: check logic and fake switches; reversible.

<objective>
Make Coexistence, H-09 and H-13 report what really happened: compare with the start of the run, and treat a failed read as a failure, not as "nothing found".

Purpose: SC1 for 1.1 WR-05, WR-02 and WR-08 (named in ROADMAP SC1), proven red then green (SC2).
Output: snapshot_old_folders, a failing snapshot_old_containers, record_old_layout, the reworked Coexistence, scoped H-09 volumes, H-13 status handling, three fake switches, new cases.
</objective>
