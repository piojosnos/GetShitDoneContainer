## Conventions carried into every edit

- Stock bash 3.2 style even for Linux-only tests (they source the host library); braces always, blank lines around control flow, full variable names, collection names ending in List/Set/Map, ASCII only, no planning IDs in code, comments or docs, no dashes as punctuation, punctuation outside closing quotes.
- Comment shape (D-11, D-12): rule line = `#`, a space and 78 hyphens (80 columns) at column 0; banner = rule, one title line (at most 80 columns), rule; optional why block of at most two lines, closed by a rule; file header right after the shebang in the same shape (purpose title; usage plus at most one other line); comments inside a function body at most two lines in a row and only the why.
- Docs (tests/README.md, SANDBOX.md): match the neighbours (tests/host-checklist.md voice: short, schematic tables); simple words; no dashes as punctuation.
- In the agent tool shell `grep` is a function that runs ugrep; verify commands use `command grep`.
