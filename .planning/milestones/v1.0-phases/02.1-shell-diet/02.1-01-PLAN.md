## Phase Goal

ROADMAP.md Phase 2.1 goal (verbatim): "The repo carries only the shell one person can maintain. About 620 lines of shipped scripts do the work; the checks around them shrink to what protects the images and the sandbox."

The roadmap marks this phase `mvp`, but the goal line is not in user-story form. As in the earlier phases it is quoted verbatim; run `/gsd-mvp-phase 2.1` if a user story is wanted.

This plan is the supply-chain gate for the two new linter pins (D-01). It mirrors the Phase 2 pin approval (02-PINS.md): every value is resolved from its authority on the day of the run, shown to the user, and only an approved row may later become a versions.env line. It writes no code.
