### `base/sbx-entrypoint` (entrypoint, request-response)

**Analog:** `claude/start.d/10-best-practices` (layout), plus its own current hook loop (lines 42-56).

**Layout pattern** (`claude/start.d/10-best-practices` lines 1-30): shebang and `set -eu`, header comment bullets, globals, then banner blocks.
```bash
# --------------------------------------------------------------------------------
# Stops the start when the config folder or the bundle is missing
# --------------------------------------------------------------------------------
check_inputs() {
  if [ -z "$configDir" ]; then
    echo "[sbx] ERROR: CLAUDE_CONFIG_DIR is not set." >&2
    exit 1
  fi
```
Banner is `# ` plus 80 dashes (82 chars). Declare `local` on its own line, assign on the next.

**Core pattern to keep verbatim** (`base/sbx-entrypoint` lines 21-35): `is_mount`, `die`, the three `||  die` checks and two folder checks. Move into `check_workspace_mount` (l.30-32), `check_project_and_state_folders` (l.34-35), `create_state_dirs` (l.37-40). Call as plain statements (no `||`/`if`, `set -e` is ignored there). Move `hookDir=/etc/sbx/start.d` up to the globals. Add a comment above `die`.

**WR-04 change** (current l.47-56 -> `run_start_hooks`; replace the `-f || -x` skip):
```bash
for hook in "$hookDir"/*; do
  if [ ! -f "$hook" ]; then
    continue
  fi

  if [ ! -x "$hook" ]; then
    echo "[sbx] ERROR: start hook $hook is not executable; the container was not started." >&2
    exit 1
  fi

  if ! "$hook"; then
    echo "[sbx] ERROR: start hook $hook failed; the container was not started." >&2
    exit 1
  fi
done
```
**Main** wraps calls in `if [ "${BASH_SOURCE[0]}" = "$0" ]; then ... exec "$@"; fi` so tests can source it in a subshell. Add a header bullet for the non-executable case. Keep comments free of `npm npx pip apt curl wget` words and planning IDs (guard scans comments).

**Reporting block to move verbatim into `lib-report.sh`** (`lib.sh` lines 300-337: `problemList=()`, `add_problem`, `report_check`, `first_lines`):
```bash
problemList=()
add_problem() {
  problemList+=("$1")
}
# The count is tested first: bash 3.2 with set -u treats an empty array as unbound.
report_check() {
  local checkId=$1 ...
  if [ "${#problemList[@]}" -gt 0 ]; then
    fail "$checkId" "$failSummary" "${problemList[@]}"
    exit 1
  fi
  pass "$checkId" "$passText"
  exit 0
}
```

## Shared Patterns

### Section banner
**Source:** `claude/start.d/10-best-practices:17-19`. **Apply to:** every in-scope script. `# ` + 80 dashes, one-line description, closing rule; `Main / Entry Point` banner above the top-level flow.

### Reporting
**Source:** `tests/host/lib.sh:300-337` (moving to `lib-report.sh`). **Apply to:** every host check. Collect with `add_problem`, end with `report_check`, `stop_check` or `pass_check`; never call these inside `$(...)` or a pipe stage.

### Conventions
Braces always; blank line before and after each `if/for/while`; full names; `xList` suffix for collections; ASCII only; no dash punctuation; no planning IDs (`D-NN`, `Phase`, `WR-`) in comments; only `sbx-hosttest`, `sbx-base`, `sbx-claude` names in `tests/host/`; no `rm`, `read`, `declare -A`, `mapfile`, `sed -i`, bare `timeout` in `tests/host/*.sh`; bash 3.2 and BSD tools.
